# Personal Portfolio

## About the Project

This project is a personal portfolio website created using HTML, CSS, and JavaScript. It introduces me and showcases my skills, projects, and hobbies.

## Features

- About Me section with a profile photo.
- Skills section showcasing my technical skills.
- Projects section with links to GitHub repositories.
- Hobbies section.
- Contact form.
- Dark mode toggle using JavaScript.
- Responsive layout using CSS Flexbox and media queries.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

- `index.html` — Website structure.
- `style.css` — Website styling and layout.
- `script.js` — Dark mode functionality.
- `assets/` — Images used in the website.

## How to Run

Open `index.html` in a web browser to view the portfolio.
